## 3. Guide Pratique pour Enregistrer la Vidéo sur votre Poste
Si vous souhaitez réaliser la capture vidéo d'écran de cette démonstration :
1. Lancez l'application via `10_Deploiement/start_dashboard.bat`.
2. Ouvrez l'outil gratuit Windows de capture vidéo (raccourci **Touche Windows + Alt + R** ou barre de jeu Xbox / OBS Studio).
3. Suivez pas à pas les 5 séquences chronométrées ci-dessus.
4. Enregistrez le fichier obtenu dans le dossier `08_Video_Demonstration/`.
