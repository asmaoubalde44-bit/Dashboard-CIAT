## 🏛️ Présentation Générale du Projet
Dans le cadre de l'évaluation pratique du cours d'Intelligence Artificielle Générative, notre équipe pluridisciplinaire a conçu et déployé la solution complète pour le **Projet 3 : Tableau de bord décisionnel du CIAT**.

Cette plateforme permet à la direction de l'ISEP, à la coordination de l'incubateur et aux partenaires d'analyser en temps réel les performances d'incubation, de surveiller le calendrier des jalons techniques, de garantir la parité de genre et d'interroger la base de données en langage naturel via un **Assistant Décisionnel propulsé par l'IA générative**.

## ⚡ Instructions de Lancement Rapide pour le Jury

### Méthode 1 : En 1 Double-Clic (Recommandée sous Windows)
Double-cliquez directement sur :
```text
10_Deploiement/start_dashboard.bat
```
Le serveur local démarre automatiquement et votre navigateur par défaut s'ouvre sur **`http://localhost:3000/`**.

### Méthode 2 : Lancement en Ligne de Commande
```bash
cd "03_Application_Dashboard"
node server.js
```
Puis accédez à `http://localhost:3000/` depuis n'importe quel navigateur.
